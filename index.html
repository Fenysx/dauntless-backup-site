Dauntless Backup

Proteção de dados e cópias de segurança do servidor Dauntless.

Sobre o projeto

Dauntless Backup é uma ferramenta privada de administração utilizada para criar e armazenar cópias de segurança dos dados do servidor comunitário Dauntless.

Como funciona

A ferramenta cria cópias de segurança do banco de dados e utiliza o rclone para enviar arquivos criptografados ao Google Drive autorizado pelo administrador.

Privacidade e segurança

O acesso ao Google Drive é autorizado pelo proprietário da conta. Os arquivos de backup são criptografados antes de serem enviados para armazenamento.

Política de Privacidade

Dauntless Backup — Ferramenta privada de administração.
